# SSF Morocco RP — ELITE Portal

نسخة محسّنة من بوابة SSF Morocco RP، مبنية على HTML وCSS وJavaScript عاديين لتناسب GitHub Pages دون build tools أو مكتبات JavaScript خارجية.

## الملفات

- `index.html` — بنية الموقع وأقسامه.
- `style.css` — الهوية البصرية المتجاوبة، الحركة، دعم RTL/LTR وتقليل الحركة.
- `app.js` — تبديل اللغات، استمارة متعددة المراحل، حفظ محلي، QCM، النتيجة والتصحيح ولوحة تجريبية.
- `data/content.json` — الرتب، الأخبار، القوانين، الأسئلة الشائعة، ورابط Discord.
- `data/exams.json` — بيانات الامتحانات والأسئلة والإجابات الصحيحة وعتبة النجاح.
- `favicon.svg` — أيقونة الموقع.
- `supabase-schema.sql` — مخطط أولي اختياري للربط الخلفي (راجع التحذيرات قبل استخدامه).

## التشغيل

لأن ملفات البيانات تُحمّل بواسطة `fetch`، افتح الموقع من خادم محلي بدلاً من فتح `index.html` مباشرة:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000` داخل مجلد المشروع. يمكن أيضاً استعمال إضافة Live Server في محرر الأكواد.

## النشر على GitHub Pages

1. احتفظ بنسخة احتياطية من المستودع الحالي.
2. فك ضغط المشروع، ثم ارفع **محتويات** المجلد إلى جذر مستودع `ssf-morocco-rp` مع استبدال الملفات المقصودة.
3. تأكد أن `index.html` موجود في الجذر.
4. في GitHub افتح **Settings → Pages** واختر `Deploy from a branch`، ثم `main` و`/(root)`.
5. انتظر انتهاء النشر وافتح رابط GitHub Pages.

لا يمكنني رفع التعديلات مباشرة إلى مستودعك من هذه الحزمة؛ يجب عليك رفعها بنفسك إلى GitHub.

## التعديل

- اللغة الافتراضية `ar`، واللغات المتاحة `ar`, `fr`, `en`. نصوص واجهة المستخدم في كائن `copy` داخل `app.js`.
- الرتب والأخبار والقوانين والأسئلة الشائعة في `data/content.json`.
- أسئلة QCM في `data/exams.json`. لكل سؤال `id`, و`text`, و`answers`, و`correct` (فهرس يبدأ من صفر)، و`explanation`.
- عتبة النجاح الافتراضية `passMark` في `data/exams.json`، ويمكن تغييرها في واجهة الامتحان.
- رابط Discord في `discordUrl` داخل `data/content.json`. اتركه فارغاً إن لم يكن الرابط جاهزاً.

## حدود مهمة وخصوصية

- الاستمارة تحفظ بياناتها في `localStorage` على نفس المتصفح والجهاز فقط؛ لا تُرسل الطلبات إلى الإدارة ولا تتشارك بين الأجهزة.
- لوحة التحكم واجهة تجريبية محلية، وليست لوحة إدارة آمنة ولا يوجد فيها تسجيل دخول حقيقي.
- نتيجة QCM تُحسب في المتصفح ويمكن التلاعب بها؛ ليست شهادة رسمية ولا نتيجة مقاومة للغش.
- لا تجمع بيانات حساسة في النسخة الثابتة. عند الحاجة إلى طلبات حقيقية، اربط Backend موثوقاً أو خدمة نماذج مناسبة، وفعّل المصادقة وسياسات الوصول، ولا تضع مفاتيح سرية داخل ملفات الواجهة العامة.
- ملف `supabase-schema.sql` قالب بداية يحتاج مراجعة واختبارات أمنية قبل استعماله. لا تستخدم مفتاح `service_role` في المتصفح.
- المشروع مستقل للـRoleplay الافتراضي، ولا يمثل مؤسسة حكومية حقيقية.
